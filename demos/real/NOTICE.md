## Allowed use (free V1)

Per ExerciseDB free-tier docs at the time of curation:

- **Allowed:** personal projects, prototypes, educational tools, non-commercial apps, community-driven fitness platforms
- **Not allowed without a paid AscendAPI/RapidAPI plan:** commercial products, SaaS, or monetised use
- **Media:** free tier provides 180p GIF format
- **Attribution:** credit to AscendAPI is required in any project using this dataset

This pack redistributes only the free CDN GIF assets needed for Rei’s Fitness Coach How-to demos, with attribution metadata baked into `mapping.json`.

## No SVG redraws

Assets here are **photoreal / filmed ExerciseDB GIFs**, not hand-drawn SVG teaching sequences. Prefer these over `/demos/` SVG frame packs when both exist for the same plan id.
